# Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| `Ctrl + Shift + N` | Новый проект |
| `Ctrl + Shift + O` | Открыть проект |
| `Ctrl + S` | Сохранить |
| `Ctrl + Z` / `Ctrl + Y` | Отменить / Повторить |
| `Ctrl + F` / `Ctrl + H` | Поиск / Заменить |
| `Ctrl + G` | Перейти к строке |
| `Ctrl + /` | Закомментировать строку |
| `Ctrl + Shift + M` | Добавить метку |
| `Ctrl + Alt + M` | Книга меток |
| `Ctrl + E` | Показать/скрыть консоль |
| `Ctrl + Shift + + / - / 0` | Масштаб окна |
| `Ctrl + Alt + + / - / 0` | Масштаб редактора |

Настройте отображение в меню **Справка**: шрифт редактора, язык интерфейса и документация Typst.

Чтобы снова открыть это обучение: меню **Справка** > **Открыть обучение**.
