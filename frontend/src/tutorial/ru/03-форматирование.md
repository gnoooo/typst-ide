# Форматирование текста

На панели инструментов есть **B** (жирный), **I** (курсив) и **U** (подчёркнутый). Выделите текст и нажмите кнопку — соответствующий синтаксис Typst будет вставлен.

Можно также писать разметку напрямую:

```typst
*жирный текст*
_курсивный текст_
#underline[подчёркнутый текст]
```

Совет: выделите слово и используйте `Ctrl + B`, `Ctrl + I` или `Ctrl + U`.

Доступны и другие виды форматирования (например, выделение через `#highlight[...]`) — всё, что умеет Typst.

Подробнее: https://typst.app/docs/tutorial/formatting/
