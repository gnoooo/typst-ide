# Блокнот

**Блокнот** хранит повторно используемые фрагменты: модули `#import`, функции и т. п.

У каждой заметки есть область видимости:
- **Общая**: доступна во всех ваших проектах.
- **Проект**: доступна только в текущем проекте.

Откройте блокнот кнопкой ^sticky_note_2^ на панели инструментов или через меню **Правка** > **Открыть блокнот**. Найдите заметку через строку поиска и вставьте её в позицию курсора редактора.
