# Добро пожаловать в Typst IDE

Typst IDE — локальный редактор для [Typst](https://typst.app), современного и мощного языка вёрстки, сочетающего LaTeX и Markdown.

Интерфейс состоит из двух основных областей:
- **Редактор** (слева): здесь вы пишете текст, структуры и другие элементы документа.
- **Предпросмотр** (справа): предпросмотр документа, скомпилированного Typst.

Как только вы вводите текст в документе, он автоматически обновляется в предпросмотре.

Пример:
```typst
#set text(size: 14pt)

= Введение

Привет, *мир*! Этот документ компилируется в реальном времени.
```

Примечание:
- Небольшие и не очень сложные документы отображаются почти мгновенно.
- Тяжёлые документы (более 18 страниц с множеством сложных структур и изображений) отображаются медленнее.
