# Управление файлами проекта

**Менеджер файлов** (кнопка ^folder_managed^ на панели инструментов или меню **Правка** > **Управление файлами проекта**) показывает полное дерево проекта.
- Папки (^folder^) можно разворачивать для просмотра проекта.
- Перетаскивайте файлы и папки, чтобы переместить их.
- Можно импортировать файл в проект.
- **Новая папка** создаёт папку в корне.
- Щёлкните по файлу правой кнопкой мыши — откроется более тонкое управление каждым элементом.
