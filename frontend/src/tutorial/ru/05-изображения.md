# Вставка изображений

Просто вставьте изображение (`Ctrl + V`), когда редактор в фокусе: оно сохраняется в папку проекта `images/`, а код `#image(...)` вставляется в позицию курсора.

```typst
#image("images/photo.png", width: 60%)
```

Примечание:
- Размер можно изменить параметрами `width` или `height`.
- Подробнее: https://typst.app/docs/reference/visualize/image/

Другие способы вставить изображение:
- Кнопка **Управление файлами проекта** (^folder_managed^): наведите курсор на изображение и выберите **Вставить**.
- Окно **figure** из кнопки `#`: найдите изображение на компьютере и вставьте рисунок.
