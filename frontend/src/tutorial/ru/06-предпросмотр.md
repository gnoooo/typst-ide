# Работа с предпросмотром

Правая панель показывает непрерывно компилируемый документ. Несколько полезных настроек:
- ^zoom_in^ / ^zoom_out^: увеличение и уменьшение предпросмотра.
- **Поле масштаба**: введите процент напрямую.
- **Компилировать** (^terminal^): компилирует документ (обычно не требуется благодаря автокомпиляции).

Щёлкните по элементу в предпросмотре — курсор редактора переместится в соответствующее место исходного кода.
