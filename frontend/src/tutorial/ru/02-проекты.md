# Создание и открытие проекта

**Проект** — это папка с вашими файлами (основной `.typ`, изображения, источники и т. д.). Работа в «проекте» включает автосохранение, вставку изображений, управление файлами, заметки и библиографии.

Более наглядно эта структура выглядит так:
```plaintext
├── images/      # изображения документа
├── main.typ     # основной документ, используемый Typst для создания PDF
└── sources.bib  # файл источников и ссылок документа
```

- **Синяя мигающая** кнопка сохранения файла в левом верхнем углу (^file_save^) создаёт новый проект:
  1. Открывается окно.
  2. Введите название.
  3. Выберите расположение.
  - Всё, что вы написали, сохраняется.
- **Оранжевая мигающая** кнопка папки в левом верхнем углу (^folder_open^) открывает существующий проект из истории.

После создания или открытия проекта становятся доступны автосохранение и другие функции, требующие активного проекта.

Горячие клавиши:
- `Ctrl + Shift + N`: новый проект
- `Ctrl + Shift + O`: открыть проект
