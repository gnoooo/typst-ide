# Вставка структур

Кнопка **#** на панели инструментов открывает меню готовых структур:
  - **Таблица**: для представления информации, результатов и т. п.
  - **Сетка**: таблица без границ для размещения элементов документа (например, изображение слева, текст справа).
  - **Прямоугольник**: прямоугольник с возможностью вставки текста.
  - **Изображение с подписью**: рисунок с подписью.

Открывшееся окно проведёт вас по параметрам: размеры, выравнивание, границы, цвета и т. д. Сгенерированный код вставляется в позицию курсора.

```typst
#table(
  columns: 2,
  
  [Имя], [Возраст],
  [Алиса], [34],
)
```

Пример рисунка с изображением и подписью:

```typst
#figure(
  image("images/photo.png"),
  caption: [Фотография],
)
```
