# Метки

**Метки** — это комментарии Typst, которые Typst IDE распознаёт особым образом. Начните комментарий с ключевого слова, и редактор позаботится об остальном:

```typst
// TODO: исправить орфографию в этом заголовке
/* FIXME: этот блок нужно разделить на два */
```

По умолчанию доступно пять меток: `TODO`, `NOTE`, `COMMENT`, `FIXME` и `WARNING`. Метка активна, как только её ключевое слово (без учёта регистра) открывает комментарий `//` или блочный комментарий `/* … */` (многострочные блоки тоже учитываются).

## Что Typst IDE делает с ними

- Строка метки **выделяется** цветом метки, а тег (`// TODO:`) отображается **жирным**.
- В поле редактора появляется цветная **точка**, а в полосе прокрутки — **полоса**: все метки видны с первого взгляда.
- При наведении на строку показываются ключевое слово и сообщение метки.

## Добавление метки

Поставьте курсор в нужное место и нажмите **`Ctrl + Shift + M`** (или **Правка** > **Добавить метку**, или щёлкните правой кнопкой мыши в редакторе). Вставляется метка `// KEYTAG: `; если включено несколько меток, сначала появляется небольшой выбор.

## Книга меток

Кнопка ^chat_bubble^ на панели инструментов или **`Ctrl + Alt + M`** открывает **книгу меток** со списком всех меток текущего документа.

- **Поиск** через текстовую строку и **фильтрация** по метке с помощью цветных чипов.
- **Щёлкните** по записи — курсор перейдёт к соответствующей строке в редакторе.
- Кнопка **Добавить метку** вставляет метку в позицию курсора, и книга обновляется.

## Управление метками

**Правка** > **Управление метками** позволяет настроить список: добавить метку (`KEYTAG:` в качестве ключевого слова), изменить её название, **цвет**, включить или отключить её, а также удалить. **Сбросить к значениям по умолчанию** в любой момент восстанавливает исходный список.
