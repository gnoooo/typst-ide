# Управление библиографиями

Меню **Правка** > **Управление библиографиями** перечисляет файлы `.bib` проекта.

- **Добавить**: создаёт новый файл источников `.bib`.
- Щёлкните по библиографии, чтобы управлять её **ссылками**: добавлять, изменять или удалять записи.
- Изменяйте **название**, **стиль** (IEEE, APA и т. д.) или **путь** библиографии.
- Редактор кода (^code^) позволяет редактировать исходное содержимое файла `.bib`.

Вставка библиографии в проект:
```typst
#bibliography("refs.bib", style: "ieee")
```

Файл синхронизируется с вашими ссылками: добавьте запись в окне — она появится в `refs.bib` (и наоборот).
