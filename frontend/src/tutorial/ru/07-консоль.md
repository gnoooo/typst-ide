# Консоль и ошибки

Если в документе есть ошибка, она появляется в **консоли**. Если вы отключили автоматическое открытие консоли при ошибке, в меню **Вид** появляется красная точка — она показывает, что есть необработанная ошибка.

- `Ctrl + E`: показать или скрыть консоль.
- Включите **Вид** > **Показывать консоль при ошибке**, чтобы она открывалась автоматически.
- **Вид** > **Игнорировать ошибки**: навсегда скрыть сообщения, которые вам уже знакомы (например, `file not found`).

```typst
#let width = "10"
#rect(width: width)
// Ошибка: width ожидает длину с единицей измерения (pt, mm, cm и т. д.), а не текст
```
