# Utiliser des modèles

Les modèles sont des projets Typst prêts à l'emploi : modèle du document, images et polices.

Ouvrez le gestionnaire via le menu **Édition** > **Gérer les templates** :
- **Nouveau modèle** pour créer un modèle avec ses fichiers par défaut.
- **Instancier** (^add_box^) : copie le modèle dans votre projet courant.
