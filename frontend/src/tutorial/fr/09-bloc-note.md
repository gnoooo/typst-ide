# Le bloc-note

Le **bloc-note** enregistre des extraits réutilisables : modules `#import`, fonctions, etc.

Chaque note a une portée :
- **Globale** : Disponible dans tous vos projets.
- **Projet** : Disponible uniquement dans le projet courant.

Ouvrez-le via le bouton ^sticky_note_2^ de la barre d'outils ou le menu **Édition** > **Ouvrir le bloc-note**. Cherchez une note avec la barre de recherche, puis insérez-la au curseur de l'éditeur.
