# Les raccourcis clavier

| Raccourci | Action |
| --- | --- |
| `Ctrl + Shift + N` | Nouveau projet |
| `Ctrl + Shift + O` | Ouvrir un projet |
| `Ctrl + S` | Sauvegarder |
| `Ctrl + Z` / `Ctrl + Y` | Annuler / Rétablir |
| `Ctrl + F` / `Ctrl + H` | Chercher / Remplacer |
| `Ctrl + G` | Aller à la ligne |
| `Ctrl + /` | Commenter la ligne |
| `Ctrl + E` | Afficher la console |
| `Ctrl + Shift + + / - / 0` | Zoom de la fenêtre |
| `Ctrl + Alt + + / - / 0` | Zoom de l'éditeur |

Personnalisez l'affichage depuis le menu **Aide** : police de l'éditeur, langue de l'interface et documentation Typst.

Pour revoir ce tutoriel à tout moment : menu **Aide** > **Ouvrir le tutoriel**.
