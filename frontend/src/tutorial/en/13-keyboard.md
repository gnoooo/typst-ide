# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + Shift + N` | New project |
| `Ctrl + Shift + O` | Open project |
| `Ctrl + S` | Save |
| `Ctrl + Z` / `Ctrl + Y` | Undo / Redo |
| `Ctrl + F` / `Ctrl + H` | Find / Replace |
| `Ctrl + G` | Go to line |
| `Ctrl + /` | Toggle line comment |
| `Ctrl + E` | Toggle console |
| `Ctrl + Shift + + / - / 0` | Window zoom |
| `Ctrl + Alt + + / - / 0` | Editor zoom |

Customize the display from the **Help** menu: editor font, interface language and Typst documentation.

To review this tutorial at any time: **Help** > **Open tutorial**.
