# Inserting images

Simply paste an image (`Ctrl + V`) while the editor has focus: it is saved into the project's `images/` folder and the `#image(...)` code is inserted at the cursor.

```typst
#image("images/photo.png", width: 60%)
```

Other ways to insert an image:

- ^folder_managed^ **Manage project files** button: hover an image and choose **Insert**;
- **figure** modal from the `#` button: browse or import a file with preview.
