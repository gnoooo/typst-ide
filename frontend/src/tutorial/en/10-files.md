# Managing project files

^folder_managed^ The **file manager** (toolbar button or **Edit** > **Manage project files**) displays the full project tree.

- ^unfold_more^ expand folders to explore the project;
- drag and drop a file or folder to move it;
- ^upload_file^ **Import**: add new files to the project;
- ^create_new_folder^ **New folder**: create a folder at the project root;
- ^delete^ **Delete**: remove a file or folder (with confirmation).

Hover a file to show its actions:

- an image: ^add_photo_alternate^ **Insert** (`#image(...)` code) or hover preview;
- a `.bib` file: open the bibliography manager.
